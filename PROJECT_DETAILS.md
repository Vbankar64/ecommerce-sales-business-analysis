# Project Details

## Project Name
E-Commerce Sales & Business Performance Analysis

## Project Objective
To analyze e-commerce business data and generate actionable insights into sales, profitability, customer behavior, product performance, and order fulfillment.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Excel Formulas
- Interactive Slicers

## Key Analysis Areas
1. Overall Sales Performance
2. Monthly Revenue Analysis
3. Product Performance
4. Category Performance
5. Customer Analysis
6. Order Status Analysis
7. Business Insights and Recommendations

## Key Performance Indicators
- Total Revenue: ₹5,18,350.70
- Gross Profit: ₹1,73,948.61
- Total Orders: 200
- Registered Customers: 100
- Purchasing Customers: 90
- Units Sold: 384
- Average Order Value: ₹2,591.75

## Key Finding
November 2025 was the highest-revenue month, generating ₹71,080.70.
